# Plant Disease Detection and Prevention

## Overview
A deep learning project that detects plant diseases from leaf
images and provides disease-related recommendations.

## Technologies Used
- Python
- TensorFlow and Keras
- CNN and EfficientNetB0
- OpenCV
- Flask
- NumPy
- Pillow

## Features
- Plant disease classification
- Image upload and prediction
- Prediction confidence display
- Disease prevention recommendations
- Live camera classification

## How to Run

1. Install Python.
2. Install the dependencies using:
   pip install -r requirements.txt

3. Ensure final_plant_model.keras and class_names.json
   are present in the project folder.

4. Run:
   python app.py

5. Open the local URL displayed in the terminal.
